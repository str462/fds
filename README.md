# FitPass Booking (Render + Upstash)

Версия для **бесплатного Render**.  
Заявки сохраняются в **Upstash Redis** (бесплатно) и сразу появляются в админке.

---

## 1. Создай бесплатную базу Upstash (2 минуты)

1. Зайди на https://console.upstash.com  
2. Зарегистрируйся (можно через GitHub).  
3. Нажми **Create Database** → выбери регион ближе к тебе → **Free**.  
4. После создания открой базу и скопируй:
   - `UPSTASH_REDIS_REST_URL`
   - `UPSTASH_REDIS_REST_TOKEN`

---

## 2. Переменные окружения на Render

В своём сервисе на Render → **Environment** добавь:

| Key                         | Value                          |
|-----------------------------|--------------------------------|
| `ADMIN_USER`                | `admin` (или свой логин)       |
| `ADMIN_PASS`                | твой пароль                    |
| `SESSION_SECRET`            | любая длинная случайная строка |
| `UPSTASH_REDIS_REST_URL`    | из Upstash                     |
| `UPSTASH_REDIS_REST_TOKEN`  | из Upstash                     |

---

## 3. Деплой

1. Замени файлы в своём репозитории на содержимое этого ZIP (особенно `server.js` и `package.json`).
2. Запушь на GitHub.
3. Render сам сделает новый деплой.
4. Готово — заявки теперь сохраняются постоянно и сразу видны в админке.

---

## Локальный запуск

```bash
npm install
# можно без Redis — будет работать в памяти
npm start
```

Открой http://localhost:3000

---

## Важно

- Без `UPSTASH_REDIS_REST_URL` и `TOKEN` данные хранятся только в памяти и пропадут при рестарте сервиса.
- На бесплатном Render сервис «засыпает» после ~15 минут бездействия. При первом запросе он просыпается (может занять 10–30 сек).
